## Detailed description
RainCheck is a small, focused extension for Claude.ai that gives you two things:

**1. Usage bars (claude-counter style)**
Keep an eye on your Claude.ai limits with live progress bars for your **5-hour
session** and **7-day weekly** usage, each with a countdown to the next reset.
Click the row to refresh. Data comes from Claude.ai's own usage API — the same
numbers your Claude.ai account uses — so you always know how much room you have
left.

**2. One-click handoff summary**
When a session is interrupted (rate limit, or you just want to switch devices),
press **Generate Summary**. RainCheck reads your current conversation from
Claude.ai and produces a clean, ready-to-paste **Markdown transcript** —
conversation title, Claude's saved summary, and your messages in order, with any
generated files included as code blocks. All the internal noise (ids,
timestamps, tool internals) is stripped out, so another AI can pick up exactly
where you left off.

### How it looks
- A small, cute **orange smiling cloud** floats on the page — drag it anywhere.
- Click the cloud to open the panel with the **Generate Summary** button.
- The panel opens right next to the cloud wherever you dragged it.

### Privacy
RainCheck runs entirely in your browser. It only talks to Claude.ai using your
existing login — the same API calls the Claude.ai page itself makes — and sends
nothing to any external server. No account, no tracking, no data collection.
See the privacy policy for details.
