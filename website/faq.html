RainCheck is a Chrome extension for Claude.ai with two features: it shows your session (5-hour) and weekly usage as progress bars with reset countdowns, and it lets you generate a clean markdown summary of your conversation so you can continue it elsewhere.
Yes, RainCheck is completely free. No subscription, no paid tiers.
No. RainCheck has no sign-in or account of its own. It uses the Claude.ai account you're already logged into, directly in your browser.
No. Everything runs locally in your browser. RainCheck only talks to Claude.ai using your existing login — the same API calls the Claude.ai page itself makes — and sends nothing to any third party. There's no server, no tracking, no analytics.
No. RainCheck is built specifically for Claude.ai and only runs on claude.ai.
The session bar shows how much of your 5-hour rolling window you've used, and the weekly bar shows your 7-day usage. Each shows a percentage and a countdown to when it resets, so you always know how much room you have left.
Claude.ai's usage API only exposes utilization percentages, not exact token counts. RainCheck shows the exact percentages the API provides, which is the same data Claude.ai uses for its own usage display.
If a session is interrupted by a rate limit, or you just want to switch devices, the handoff summary turns your conversation into a clean markdown transcript (title, Claude's saved summary, and your messages in order, with generated files included). You can paste it into another AI or a new session to continue exactly where you left off.
